    BEFORE • DURING • AFTER

    Make your training log useful

    01

    Use consistent names

    Record the same exercise under the same name each time. “Leg press” is easier to compare with “Leg press” than with a collection of abbreviations. Select the category that helps you find the entry later.

    02

    Record what you completed

    Enter completed sets and reps instead of a planned result. Use zero weight for a bodyweight entry. This version records repetitions and pounds; it does not yet have fields for distance, duration, or workout dates.

    03

    Review before the next session

    Look back at the saved list and check that each entry makes sense. Remove sample entries when you want a log of only your own work. Switch profiles before adding an entry if more than one person uses this browser.
