ZTIME PROFILE + ABOUT UPDATE

This version adds:
- Multiple browser-based demo profiles
- Create profile
- Log in
- Log out
- Switch between saved profiles
- Separate workout history and weekly goal for each profile
- A personalized About page telling Chris Ziegler's ZTime story and vision
- The "WHAT TIME IS IT?! / ZTIME — LET'S GET IT!" call-and-response

IMPORTANT:
The profile feature is a course demo using localStorage in the browser.
It does NOT use passwords, a server, or secure real-world authentication.
